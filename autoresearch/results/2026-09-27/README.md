# LLM decode 최적화 실행 결과

Colab CLI를 0.6.0에서 0.7.4로 업데이트하고 A100과 TPU v6e에서 각각 30개 후보를 병렬로 평가했다. TPU v6e 할당에 성공해 v5e 대체 실행은 필요하지 않았다. 원래 baseline 소스는 보존하고 선택된 모델을 각 결과 디렉터리의 `best_model.py`에 저장했다.

아래는 각 장치의 **자체 시작 후보 대비** 개선이다. 고정 크기의 무작위 가중치 모델을 대상으로 한 decode 실험이며, 하드웨어 간 우열이나 학습된 모델의 품질을 평가한 결과는 아니다.

| 실행 | 시작 후보 | 두 번 확인한 최고 기록 | 지연 시간 단축 | 선택된 방법 |
|---|---:|---:|---:|---|
| [A100 상세 기록](gpu/report.md) | 7.5135 ms | 2.4385 ms | 67.5% | CUDA graph + BF16 반올림을 보존하는 Triton RoPE |
| [TPU v6e 상세 기록](tpu/report.md) | 1.9000 ms | 1.8504 ms | 2.6% | JAX QKV projection 통합 |

현재 최고보다 1% 넘는 개선을 별도 프로세스 두 번에서 확인해야 채택했고, 두 측정 중 느린 값을 기록했다. 정확도 실패는 성능 기록에서 제외했다. 전체 logits와 모든 층의 KV cache를 고정 허용 오차로 검사했다.

최종 독립 재검증에서 양쪽 모두 prefill·decode 정확도 검사를 통과했다. decode는 A100 2.4363 ms, TPU 1.8529 ms였으며 양쪽 모두 기준 구현과 최대 오차가 0이었다. **TPU 최고 모델의 prefill은 9.2301 ms로 같은 실행의 기준 구현 6.9804 ms보다 약 32.2% 느렸다.** decode용 최적화 결과로 해석해야 한다.

A100 CUDA graph는 재사용하는 입력 버퍼를 대상으로 측정했다. 입력 주소나 shape가 바뀌면 새 캡처가 필요하며, 서비스 적용에는 graph cache 수명 관리가 추가로 필요하다.

- 각 상세 기록에는 실험 진행 그래프, 30개 가설과 결과, 최고 모델 소스가 있다.
